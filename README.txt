# Birthday Surprise Website ❤️

A single-page birthday surprise website with animated hearts, confetti, a personal message, photo gallery, and music player.

## Run
1. Extract `Birthday-Surprise.zip`.
2. Open the `Birthday-Surprise` folder.
3. Double-click `index.html` to open it in Chrome, Edge, or another modern browser.

## Personalize
Open `index.html` in Notepad.
At the top of the JavaScript section, edit:
- `GIRL_NAME`
- `MESSAGE`

Save the file and refresh the browser.

## Persistent photo and music storage
Uploaded photos and music are saved in the browser's IndexedDB database. They remain available after refreshing or reopening the page in the same browser profile on the same device.

Important:
- Browser storage is local to that browser/device; it does not sync to other devices.
- Clearing browser site data, using private/incognito mode, or browser storage cleanup can remove saved uploads.
- Keep the same browser profile and don't clear its site data.
- Browsers require a user click to start audio playback after reopening.
